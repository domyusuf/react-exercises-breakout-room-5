# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

## Clone, Open, and Run

Clone the repository and move into the React project directory:

```bash
git clone https://github.com/domyusuf/react-exercises-breakout-room-5.git
cd react-exercises-breakout-room-5/breakout-room-5
```

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal, usually [http://localhost:5173](http://localhost:5173). If that port is already in use, Vite will provide an alternate port such as `5174`.

To check the project before committing changes, run:

```bash
npm run lint
npm run build
```
